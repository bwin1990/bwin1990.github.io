# Welcome to heyoutaoyuan

This blog has been redesigned with a **Hacker News inspired minimal style**. Here's what's new:

## 🎨 Design Features

- **Clean, minimal interface** inspired by Hacker News
- **Dark/Light theme toggle** - try clicking the 🌙/☀️ button in the sidebar
- **Responsive design** that works great on mobile devices
- **Fixed header** that hides when scrolling down and shows when scrolling up

## 📱 New Functionality

### Navigation & UI
- **Mobile-friendly navigation** with collapsible menu
- **Improved typography** optimized for readability
- **Search functionality** - try searching for posts in the sidebar
- **Reading progress indicator** on article pages

### Article Features
- **Table of Contents (TOC)** auto-generated from headings
- **Reading time estimation** displayed with each post
- **Related posts** suggestions based on tags and categories
- **Social sharing buttons** for Twitter, Facebook, and direct link copying
- **Page view counter** using localStorage
- **Article pinning** - this post is pinned to the top!

### Enhanced User Experience
- **Smooth scrolling** for internal links
- **Theme persistence** - your dark/light mode choice is remembered
- **Optimized performance** with debounced search and scroll handlers

## 🔧 Technical Improvements

- **Modern CSS** with CSS custom properties for theming
- **Improved JavaScript** with better error handling and performance
- **SEO optimizations** with proper meta tags and structured data
- **Print-friendly styles** for when you need to print articles

## 📝 Content Organization

Posts are now organized with:
- **Numbered list view** similar to Hacker News
- **Better categorization** and tagging system  
- **Pagination** increased to 10 posts per page
- **Improved metadata** display with dates, categories, and read time

---

This redesign maintains the blog's functionality while providing a cleaner, more focused reading experience. The minimal aesthetic helps you focus on the content while still providing all the modern features you'd expect from a contemporary blog.

Enjoy exploring the new design!
